# Contact and support

**Hardware / integration support:** [support@sharpa.com](mailto:support@sharpa.com), from the Avatar user manual's Contact Support section.

For an adapter, documentation or calibration question, include:

- Tracker/controller model and firmware/runtime version.
- Avatar hardware revision and left/right hand.
- CAD filename, SHA-256 from `catalog/assets.json`, and any local modifications.
- Photos of the assembled mount and a clear description of fit or retention problems.
- For transforms: runtime pose frame, units, source pose, expected pose and measured result.

Use [GitHub Issues](https://github.com/sharpa-robotics/sharpa-avatar-tracker-mounts/issues) for reproducible repository defects. The issue template requests the same information.

Vendor runtime, pairing and SDK issues should also be checked against the [official device references](docs/references.md). This repository does not include a live tracking driver.
